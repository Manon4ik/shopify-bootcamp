assets : CSS, JavaScript, изображения, шрифты и другие статические ресурсы темы.
config : настройки темы
layout : глобальный каркас страницы (theme.liquid), который подключает шаблоны, ресурсы и общий HTML-документ.
locales: фалы перевода для разных языков
sections : описание логики и структуры всех секций
snippets : маленькие переиспользуемые блоки
templates : определяют, какие Sections будут отображаться для конкретного типа страницы (в OS 2.0 это чаще всего JSON).
