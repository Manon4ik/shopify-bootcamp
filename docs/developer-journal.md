🚀 Senior Challenge

Найди самостоятельно ответ.
Почему templates/ содержит product.json а не product.liquid Что изменилось? Ответ написать своими словами.

Ответ : 
product.json
↓
говорит какие Sections должны быть
↓
Sections сами написаны на Liquid

То есть:
JSON отвечает за композицию страницы.
Liquid отвечает за реализацию компонентов.
