Liquid: 
Шаблонизатор Shopify. Генерирует HTML на сервере до отправки страницы пользователю. {{ product.title }}


Object:
Объект с данными магазина, товаров, коллекций, корзины и т.д.
product, collection, cart, shop. 
"Что показать?" (данные)

Tag:
Логика Liquid: условия, циклы, переменные, подключение шаблонов. Записываются в {% %}.
{% if %}, {% for %}, {% render %}
"Что сделать?" (логика)

Filter:
Функция, изменяющая значение объекта. Используется через `
`.
Filter → "Как показать?" (форматирование)

Render:
Подключает сниппет в изолированной области видимости (scope). Современная замена include.
{% render 'product-card', product: product %}
"Подключить другой шаблон"


Assign:
Создает новую переменную.
{% assign sale = product.compare_at_price %}
"Запомнить значение"

Capture:
Сохраняет блок текста или HTML в переменную.
{% capture button %}<button>Buy</button>{% endcapture %}
"Запомнить целый кусок HTML"

Scope:
Область видимости переменных. Переменные доступны только в своем контексте. render создает собственный scope.
assign внутри render не влияет на родительский шаблон.
"Где видна переменная"
